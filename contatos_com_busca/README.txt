CONTATOS COM BUSCA EM TEMPO REAL

Conteúdo:
- App.js: aplicativo completo, pronto para usar no Expo Snack.
- README.txt: instruções e requisitos implementados.

COMO EXECUTAR NO EXPO SNACK
1. Acesse https://snack.expo.dev
2. Crie um projeto em branco.
3. Abra o arquivo App.js.
4. Substitua o código existente pelo conteúdo do App.js deste pacote.
5. Aguarde o carregamento dos contatos. É necessária conexão com a internet.

REQUISITOS IMPLEMENTADOS
1. useEffect busca os usuários da API JSONPlaceholder quando o app abre.
2. TextInput funciona como campo de pesquisa.
3. O estado busca armazena o texto digitado.
4. filter(), toLowerCase() e includes() filtram os nomes em tempo real.
5. FlatList exibe os contatos filtrados.
6. ListEmptyComponent mostra uma mensagem quando nenhum contato corresponde à pesquisa.

A lista também exibe o e-mail e o telefone de cada contato.
